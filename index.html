QWEN

Qwen은 알리바바가 직접 훈련한 대규모 언어 모델 패밀리입니다. 언어와 코드를 읽고, 이미지를 보고, 사고 과정을 거쳐 답을 만듭니다. 대부분의 모델은 오픈 웨이트로 배포되어 로컬에서도 돌아갑니다.

01 / FAMILY

모델은 계열로 자란다

하나의 모델이 아니라, 크기와 목적별로 나뉜 패밀리입니다. 작은 것은 스마트폰에서도, 큰 것은 서버에서 돌아갑니다.

BASE · REASONING

Qwen3

사고 모드를 켜고 끌 수 있는 하이브리드 모델. 수학·코딩·복잡한 추론에 강하며 MoE 변형이 포함됩니다.

GENERAL

Qwen2.5

0.5B~72B까지 다양한 사이즈. 한국어 포함 다국어 지원.

VISION

Qwen-VL

이미지와 문서를 읽습니다. 표·수식·스크린샷 해석과 OCR.

CODE

Qwen-Coder

코드 생성·수정·리뷰, 에이전트 코딩 작업용.

AUDIO

Qwen-Audio

음성 입력 처리와 음성 대화 계열.

02 / HOW IT RUNS

토큰이 레이어를 통과해 답이 된다

  • 01질문을 잘게 쪼개 토큰으로 만듭니다.
  • 02어텐션 레이어가 앞 문맥과의 관계를 계산합니다.
  • 03레이어마다 값을 갱신하며 표상을 깊게 만듭니다.
  • 04다음 토큰을 예측하고, 한 글자씩 다시 토큰으로 이어 붙입니다.

04 / TIMELINE

계열의 변화

2023

Qwen 첫 공개. 이후 오픈 웨이트 체크포인트로 확장.

2024

Qwen1.5 → Qwen2. 다국어와 장문 컨텍스트가 강화됩니다.

2024.09

Qwen2.5. 코딩·수리 성능과 다양한 사이즈 라인업.

2025.04

Qwen3. 사고 모드 전환, MoE 모델 포함.

2025+

비전·코딩 계열 확장(Qwen3-VL, Qwen3-Coder 등).
